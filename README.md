# Quantum Learning Journey

I am a student exploring quantum computing from scratch out of curiosity.
All projects are built in pure Python with no frameworks like Qiskit.
The goal is to understand the math and logic before moving to real quantum hardware.

---

## Projects

### Project 1 — Quantum Coin Flipper
Teaches superposition and measurement.
A simulator that shows the difference between a classical coin flip and a quantum one.
Core concepts: qubit, amplitude, Born Rule, state collapse.
Location: Project-1-Coin-Flipper/

### Project 2 — Quantum Gate Simulator
Teaches quantum gates and matrix operations.
Applies the Hadamard Gate to a qubit and shows superposition and phase.
Core concepts: matrix multiplication, Hadamard Gate, phase, interference.
Location: Project-2-Gate-Simulator/
